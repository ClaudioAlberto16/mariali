# Mariali

App web instalable para practicar las 20 semanas (100 palabras) del Método Filadelfia.

## Activar publicación

En GitHub abre Settings → Pages → Build and deployment. Elige Deploy from a branch, branch main y folder /(root), y pulsa Save.

Dirección prevista: https://claudioalberto16.github.io/mariali/

## Instalar en Android

Abre la dirección en Chrome, menú ⋮ → Instalar aplicación / Agregar a pantalla principal.

Incluye caché básica para poder abrir la aplicación sin conexión después de visitarla una vez. Poppins se descarga de Google Fonts; sin conexión se usará una fuente de respaldo.
